# Mini E-commerce Website

A web-based Mini E-commerce Website developed using Python Flask and SQLite.

## Project Overview
This project demonstrates an online shopping platform where users can browse products and use shopping-related features through a web interface.

## Features
- User registration and login
- Product listing
- Product search
- Shopping cart
- Wishlist
- Product images
- Admin dashboard and product management
- Checkout and payment page
- Product rating system

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone this repository.
2. Open the project folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Flask application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000/
```
